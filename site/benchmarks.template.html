How we test

Small, honest, repeatable.

Setup. Cookie Away’s column is one run of version {{CA_VERSION}} on all sites; Consent-O-Matic’s comes from the same setup earlier the same day. Headless Chromium from Sweden, a fresh profile for every site, the extension loaded unpacked, 12 seconds per page. Consent-O-Matic is the official {{COM_VERSION}} release with its default settings.

What counts as rejected. The banner is gone and the site’s consent tool (TCF, OneTrust, Cookiebot or Didomi) records no consents. “Banner gone” means it went away but the site doesn’t expose what it recorded; we checked those screenshots by hand.

Pay-or-accept walls. Some sites only let you reject if you subscribe. Leaving those for you to decide counts as handled; ending on a payment page or accepting tracking doesn’t.

The catch. These are the sites we used to find and fix Cookie Away’s bugs, so the final numbers flatter it. The fairer comparison is the first run on sites Cookie Away hadn’t seen yet: there it answered {{UNSEEN_CA}} banners with a free “no”, and Consent-O-Matic {{UNSEEN_COM}}. One country, one day, and banners change all the time, so treat all of this as a snapshot.

The test scripts are in the repository under bench/. Tell us about a site and we’ll add it.
